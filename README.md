# 💰 Expense Tracker Full Stack App

This is a full-stack Expense Tracker application built with **React, Node.js, Express, and MongoDB**.  
Users can add, delete, and filter expenses by category and time period, and track total spending dynamically.

---

## 🚀 Features

- Add new expenses (amount, description, category)
- Delete expenses
- Category filtering (Food, Transport, Entertainment, etc.)
- Time filtering (Today, This Month, All Time)
- Dynamic total calculation based on filters
- Real-time UI updates
- Loading, error, and empty states

---

## 🛠️ Tech Stack

### Frontend
- React
- JavaScript (ES6+)
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose)
